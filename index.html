EVERYDAY USE CASES

从一件小事开始，
让工作更顺手。

以下是 Work Buddy 协助完成日常任务的具体场景。涉及数据和事实时，我会逐项核实。

🧾
01 · PERSONAL FINANCE

记账与收支整理

把零散的消费记录整理成清晰账目，快速了解支出类别与变化趋势。

使用步骤：提供日期、金额和用途 → 按餐饮、交通、日用品等分类 → 汇总本周支出并标出待确认项目。
✨ 从翻找零散记录，变成查看一份清楚的收支摘要；涉及金额时逐项核对。
📊
02 · PRESENTATION

制作 PPT 演示文稿

根据汇报主题和听众，先搭建逻辑结构，再逐页补充内容与表达重点。

使用步骤：说明对象与时长 → 生成大纲和页面标题 → 补充案例、图表建议与演讲备注。
✨ 先有结构，再做视觉表达；图表数据、事实来源和最终措辞由我把关。
💻
03 · CODING

编写与理解代码

请 Work Buddy 解释陌生代码、讨论实现思路、拆解报错，或协助起草代码片段。

使用步骤：描述目标与运行环境 → 讨论方案和边界情况 → 编写或修改 → 本地运行、测试并复核。
✨ 不只拿到代码，也追问“为什么这样写”，让协作同时成为学习过程。
✍️
04 · WRITING

文字整理与润色

把零散想法整理成邮件、通知或总结初稿，再根据读者和语气调整表达。

使用步骤：提供背景与目标 → 指定读者和语气 → 对照事实修改措辞与重点。
✨ 更快写出第一版，但重要信息、语气分寸和对外内容仍要亲自确认。
🗂️
05 · ORGANIZATION

计划与资料归纳

把会议记录、任务清单或较长材料整理成摘要、行动项和待确认问题。

使用步骤：提供材料 → 提取主题与行动项 → 标记负责人、时间和未决事项。
✨ 让“下一步做什么”更明确，优先级和最终安排仍由自己判断。
🔎
06 · LEARNING

学习与问题拆解

遇到新知识时，请它换种方式解释、举例或逐步推导，理清思路。

使用步骤：指出卡住的地方 → 要求分步骤讲解 → 用自己的例子验证理解。
✨ 把即时答疑变成主动学习；重要知识和关键结论再做查证。
A SIMPLE COLLABORATION LOOP

我的协作小循环

清楚的输入和认真的复核，才能让 AI 协作更可靠。

🎯说清目标

讲明背景、对象、格式和限制条件。

🤝共同起草

协助整理信息、生成初稿或探索方案。

🧐核对细节

检查数据、事实、代码行为和不确定之处。

🚀亲自交付

根据真实需要修改，最终结果由自己负责。

REFLECTION & NEXT

让工具更聪明，
也让人更专注。

使用 Work Buddy 后，我感受到它的价值不只是“更快完成任务”，也在于降低了开始一项工作的门槛：账目更容易整理，PPT 更快形成框架，代码问题也有了一个可以反复讨论的起点。但 AI 可能遗漏背景、误解需求，甚至给出看似合理却不准确的内容；核实、判断与承担责任，始终不能外包。

我期待 Work Buddy 未来能更懂个人工作习惯，在整理收支时更重视隐私，在制作演示文稿时让内容与视觉衔接得更自然，在编写代码时提供更清晰、可验证的解释与测试建议。希望它成为可靠、透明、好沟通的助手，帮助我把时间留给更有创造性、更有价值的事情。

🌱 我的心得把 AI 当协作者，而不是权威；越重要的内容，越要认真复核。
🧭 我的方法给清晰上下文，分步骤推进，及时反馈并保留自己的判断。
✨ 我的期待更懂需求、更重隐私、更透明可验证，也更贴近日常工作。
